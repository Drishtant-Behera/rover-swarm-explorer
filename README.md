# Rover Swarm Explorer

Interactive maps of a team of low-cost rovers that map GPS-denied indoor spaces together, by Drishtant Behera. Generated with Claude.

- `index.html`: the explorer, showing the end goal with what's built so far marked
- `system-map.html`: what runs today
- `planned-architecture.html`: the planned system

Live site: https://drishtant-behera.github.io/rover-swarm-explorer/
